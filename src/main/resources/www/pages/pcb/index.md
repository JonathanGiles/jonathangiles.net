I am a software engineer, who dabbles with small electronics and circuit board projects. It's gotten to the point where it is worth documenting some of the projects I've worked on, if even only for my future recollection. This page will serve as a landing page for all of my circuit board projects.

## Projects

Here are the projects that I have worked on, in rough chronological order.

### D1 Mini Expansion Boards

I had a few home automation projects at home that I wanted to elevate beyond hand-soldered vero board. I decided to design a few expansion boards for the Wemos D1 Mini, which is a small ESP8266-based microcontroller board. You can read more about these projects [here](/pcb/d1-mini-exp.html).

---

### Table Tennis Trainer

In 2023 my son happened upon a Table Tennis table when we were on vacation in Fiji. Since then he has trained weekly and become exceedingly good at Table Table. I decided to work on a project that would help him to train - in particular to improve his accuracy and reflexes. This project is still in-progress, but you can read more about the project [here](/pcb/ttt.html).

---

### Spa Pool Controller

This project is my most complex PCB to date, because it is the first one where I challenged myself to not have the ESP chip simply be a plug-in module. Instead, I wanted to have the ESP chip be the main controller on the board. This project is still in-progress, but you can read more about the project [here](/pcb/spa-control.html).
