**Short Bio**

Jonathan Giles is a Principal Architect and Principal Engineering Manager of the .NET and Java teams in CoreAI at Microsoft. He is a Java Champion, JavaOne Rockstar, and Duke's Choice award-winner.

**Long Bio**

Jonathan Giles is a Principal Architect and Principal Engineering Manager of the .NET and Java teams in CoreAI at Microsoft, where he has worked since 2017. Before this, Jonathan was a Java cloud developer advocate at Microsoft for one year, and a technical lead on the Java team at Sun Microsystems and Oracle for nine years, where he contributed to all Java releases between Java 7 and 10. He is passionate about creating excellent developer experiences with API design, documentation, testing, and tooling, and as a result of his efforts in these areas he is a Java Champion, JavaOne Rockstar, and a Duke's Choice award-winner.
