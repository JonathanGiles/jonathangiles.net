Over time I've worked on a number of open source projects and websites. The list below is an incomplete list based on my recollection, but you can also check out my GitHub for a number of smaller projects I created.

Site Builder Active

Simple static website generator / templating engine

Site Builder is a simplistic templating engine that is currently used to build JonathanGiles.net.

View on GitHub

TeenyHttpd Active

Simple HTTP Server written in Java

TeenyHttpd is an extremely basic HTTP server. It is implemented in plain Java with no external dependencies, making it lightweight and applicable in situations where a basic, small HTTP server is all that is required.

View on GitHub

ControlsFX Active

Rich UI controls library for JavaFX

I started the ControlsFX project to fill the gap between what Oracle offers in JavaFX and what the community needed. ControlsFX is an open source project for JavaFX that aims to provide really high quality UI controls and other tools to complement the core JavaFX distribution.

View on GitHub

Archived Projects

Scenic View Archived

A runtime scenegraph analyser for JavaFX

Scenic View is a JavaFX application designed to make it simple to understand the current state of your application scenegraph, and to easily manipulate properties of the scenegraph without having to keep editing your code.

View on GitHub

FXDocs Archived

The JavaFX Documentation Project

The JavaFX Documentation Project was designed to collect important JavaFX information from around the web and collate it into a single source to form a cohesive book.

View on GitHub View Website

FX Experience Archived

The premiere JavaFX website

FXExperience.com was a hugely popular JavaFX website with the latest news, interviews, and code tips. I was the sole maintainer of this website, which received over 2000 hits a day.

OpenSprinkler Archived

A Java API for OpenSprinkler devices

A Java-based library for communicating with OpenSprinkler irrigation controller devices over a local area network, used in projects such as OpenHAB for home automation.

JTivo Archived

A Java API for Tivo devices

A Java-based library for communicating with Tivo devices over a local area network, used in projects such as OpenHAB for home automation.
